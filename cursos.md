<h2>Ruta sugerida</h2>
<div class="roadmap">
  <div class="roadmap-step">
    <span class="roadmap-num">01</span>
    <h3>Elige según lo que necesitas</h3>
    <p>Si quieres resolver trámites, empieza por Transfermóvil. Si quieres programar, empieza por Python básico.</p>
  </div>
  <div class="roadmap-step">
    <span class="roadmap-num">02</span>
    <h3>No mezcles dos lenguajes a la vez</h3>
    <p>Termina las bases de Python o de C++ antes de pasar al otro. Aprender dos sintaxis al mismo tiempo confunde.</p>
  </div>
  <div class="roadmap-step">
    <span class="roadmap-num">03</span>
    <h3>Practica con algo pequeño</h3>
    <p>Repite los ejemplos y cambia una parte para ver qué pasa. Un programa propio vale más que diez videos vistos.</p>
  </div>
  <div class="roadmap-step">
    <span class="roadmap-num">04</span>
    <h3>Pasa al siguiente nivel</h3>
    <p>Cuando termines C++ básico, puedes seguir con Qt. Si terminas Python básico, pide ideas para proyectos.</p>
  </div>
</div>
